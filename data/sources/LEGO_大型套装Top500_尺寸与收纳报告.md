## 数据源与规则

- [Brickset API v3](https://brickset.com/article/52664/api-version-3-documentation)
- [Brickset Model size 的提取与轴向限制](https://brickset.com/article/121691/new-feature-model-size)
- A 级套装号链接指向 LEGO 官方产品页；其余指向 Brickset 套装页。
- 订正列方法：`官方`=沿用 A；`直录`=从产品描述恢复；`推定`=保留已知轴并补齐；`估计`=按最可能展示姿态估算；`不适用`=没有单一固定成品。方法后的高/中/低是置信度。
- 建议展示罩内尺寸为短/中/长三边各增加 5 cm，仅作选柜起始值。
- JSON 数据保留 Brickset 内部 setID、最后更新时间、发布日期及证据等级。
